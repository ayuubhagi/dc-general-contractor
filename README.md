# DC General Contractor

Website I built for DC General Contractor, a renovation company in Waterloo Region doing bathrooms, custom showers, tile, basements and decks.

The client does high-end work, so the design leans upscale: a serif display font, a project gallery up top, and a section walking through how a renovation runs from first call to final walkthrough.

Single static page (HTML, CSS and vanilla JavaScript, no framework) with work gallery, services, process, reviews and contact.

## What I focused on

- **Showing the work.** Project photos lead the page since that's what sells a renovation.
- **Local search.** Title, meta description, Open Graph tags and `GeneralContractor` structured data aimed at renovation searches in Kitchener, Waterloo, Cambridge and Guelph.
- **Mobile first.** Layout is built for phones and scales up to desktop.

## Running it

Open `index.html` in a browser. There's no build step, so any static host (Cloudflare Pages, GitHub Pages, Netlify) can serve the repo root as-is.
